## About

Cryonix is a modern, fully responsive website template for a crypto platform. It has a dark theme with orange glow accents, smooth animations, and a clean component-based structure, so it is easy to customize and extend.

## Features

- Responsive design for mobile, tablet, and desktop
- Dark theme with gradient glows and glass-style cards
- Infinite logo marquee, interactive FAQ accordion, and contact form
- Reusable, component-based code
- Optimized images with `next/image`

## Pages

| Page              | Description                                        |
| ----------------- | -------------------------------------------------- |
| `/`               | Home: hero, trusted-by logos, FAQ, and CTA         |
| `/contact`        | Contact form                                       |
| `/license`        | License info for images, fonts, and icons          |
| `/restricted`     | Password-protected access page                     |
| `404`             | Custom not-found page                              |
